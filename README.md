# DaddyEditz - Freelance Video Editor Portfolio

A modern, high-performance portfolio website built for short-form video editors, featuring dynamic animations and a premium, minimalist design.

## Features

- **Built with React, Vite, and TypeScript** for blazingly fast performance and type safety.
- **Tailwind CSS & Shadcn UI** for modern, responsive, and accessible components.
- **Framer Motion Animations**:
  - Animated marquee for hero section showcasing dynamic text and visuals.
  - Testimonial marquees (dual-row) to highlight client reviews.
  - Interactive Instagram-style "Confetti Reactions" (heart/fire bursts) on video cards.
- **Glassmorphic UI**: Translucent, floating navbar that disappears smoothly on scroll.
- **Optimized for Video**: Support for 9:16 vertical short-form content to showcase Reels, TikToks, and Shorts.

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

## Design Language

- **Aesthetic**: Premium, light-mode only.
- **Colors**: Off-white/cream background (`#F7F6F3`), deep charcoal text (`#111`).
- **Vibe**: Professional, dynamic, and highly engaging for prospective clients.
